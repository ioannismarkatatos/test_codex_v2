# test_codex_v2

This repository contains a simple console game featuring spiders. The goal is to move around a small grid and squash the spiders you find.

## Playing the game

Run the following command:

```bash
python3 spider_game.py
```

Use the **W**, **A**, **S**, and **D** keys to move your player (`P`) around the grid. Step on each spider (`X`) to squash it. When all spiders are gone, you win.
